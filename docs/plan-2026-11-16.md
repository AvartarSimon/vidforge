# 2026-11-16 方案：录像/美颜/抠像/画中画/剪辑台/多平台

需求来源：Simon 当天要用来做抖音 / TikTok / 快手 / 今日头条 / YouTube 的视频。
原则不变：免费、本地、文件驱动、不加 Docker / 数据库 / 云服务。

## 1. 需求对照（做之前的现状）

| 需求 | 做之前 | 缺什么 |
|---|---|---|
| 录像 + 提词器 | ✅ 录音棚：提词器压在画面上、设备选择、电平表、3 秒倒数 | 提词器不会自动滚动；不能调位置/速度；没有「镜像」开关 |
| 录像时换背景 | ❌（只有绿幕滤镜 `videofx.chromakey_chain()`，要真绿幕） | 不要绿幕的实时人像分割 |
| 录像时换头 / 换衣服 | 🟡 换头只有后期（`video/heads.py`：贴静图或动态头像） | 实时、逼真的换脸/换衣需要 GPU + 授权有问题的模型（见第 4 节）——**不做** |
| 美颜（可调，像抖音） | 🟡 4 个固定 ffmpeg 预设，存片时才套，看不到效果、不能调 | 实时预览 + 滑块：磨皮、美白、红润、亮度、锐化、瘦脸、大眼 |
| 后期美化声音 | ✅ 7 个人声预设 + 音高 | （Mac 上 rubberband 缺失会渲染失败 → 已修） |
| 后期美化/更换背景 | ❌ | 对已有视频套同一套抠像+美颜 |
| 画中画（圆形小窗、任意位置、可调、多画面） | 🟡 `Overlay`：9 宫格位置或 `x,y`，宽度可调，图片/视频，多个 | 圆形/圆角；拖拽摆放；分屏（左右/上下/三宫格）需要「裁满一个框」 |
| 剪辑 | 🟡 每段裁切、8 种转场、调色、BGM、字幕、竖版切片 | 没有时间线视图；没有「剪气口」 |
| 常见免费 AI | 🟡 脚本（浏览器 AI）、TTS、字幕对齐、配图关键词、看图复核 | AI 抠像、AI 美颜、智能剪口播 |
| 多平台 | 🟡 YouTube 上传、竖版切片 | 平台规格预设（抖音/快手/TikTok/头条/YouTube）一键导出 |

## 2. 任务清单（按顺序，一个功能一个提交）

1. ✅ 修：ffmpeg 没有 rubberband 时变调回退（Mac 上「低沉磁性」会让渲染失败）
2. ✅ 一键安装 `install-mac.sh` + 启动器改用 `.venv`
3. 实时特效引擎（浏览器内，MediaPipe + WebGL，免费、离线、不传任何画面出去）
   - 人像分割：背景虚化 / 换图片 / 换视频 / 纯色
   - 美颜滑块：磨皮、美白、红润、亮度、对比、锐化；人脸关键点驱动的瘦脸、大眼
   - 预设：自然 / 清透 / 质感，参数记在本机
4. 录音棚改版：录的就是看到的（录 canvas），提词器自动滚动 + 速度 + 位置 + 镜像
5. 后期美化：把已有视频过一遍同一套特效，存成新文件
6. 画中画升级：圆形 / 圆角 / 方形；分屏布局预设；在预览画面上拖拽摆放与缩放
7. 智能剪口播：按静音自动剪掉气口和停顿（ffmpeg `silencedetect`，不需要模型）
8. 多平台导出预设：抖音 / 快手 / TikTok / 今日头条 / YouTube 的画幅、码率、时长检查
9. 界面全面改版：参考剪映 / CapCut / Descript —— 深色中性底、青色强调色、紧凑密度、顶部「导出」按钮、
   新增「剪辑台」：左素材 · 中预览 · 右属性 · 底部时间线

## 3. 技术选择（我替你选的，可以改）

- **实时特效放在浏览器里，不放在 Python 里**：录像本来就在浏览器，MediaPipe Tasks Vision 的 WASM 在
  M 系列 Mac 上 1280×720 能跑 30fps；放 Python 要先录再处理，就不是「所见即所得」了。
- **模型文件**按需从 Google 的公开地址下载到 `~/.vidforge/models/`（和 YuNet 一样），只下一次；
  WASM 直接用 `node_modules` 里的，不进 git。
- **磨皮**用 WebGL 双边滤波（和 ffmpeg 预设同一个思路：只平均颜色相近的像素，不糊眼睛和头发），
  并且只作用在皮肤区域（人像分割 × 肤色）。
- **瘦脸/大眼**用 478 点人脸网格做局部径向形变，幅度上限压得很低——抖音式的过度美颜会让脸「假」，
  你要的是「不假」。

## 4. 不做的（以及为什么）

- **实时逼真换脸 / 换衣服**：能做到「不假」的开源方案（inswapper / Deep-Live-Cam、IDM-VTON 等）
  要 GPU，权重是非商用授权，并且让整条视频变成需要标注的合成内容——和这个频道「自己的脸、自己的声音」
  的定位正好相反。后期遮脸（静图/动态头像）仍然在「视频」页。
- **AI 生成背景音乐**：授权陷阱，见 features.md 第 9 节。
