# 讲解类视频的规范（爆款研究 → 可核对清单）

日期：2026-09-17 · 状态：**第一版基于既有公开研究与头部频道的公认做法**（Kurzgesagt、Veritasium、Kings and Generals、OverSimplified、Fall of Civilizations、History Matters、Vox、TED-Ed；中文：李永乐老师、回形针、小Lin说、观视频）。每条都写成可检查的规则，`vidforge/ui/static/best_practices.json` 是它的机读版，页面据此给出提示。
**待验证**：`tools/channel_study.py` 用 YouTube 数据把 20 个频道 × 前 5 条视频拉成 CSV 后，逐条核对这些阈值并修订。

## A. 平台与合规（先于一切）

| # | 规则 | 依据 |
|---|---|---|
| A1 | 脚本必须是**原创写作**：有你的判断句（"我认为/关键在于/很多人忽略"）、有对比或结论，不是维基复述 | YouTube 2025-07 inauthentic content：批量/复读/无增值 → 拒绝或撤销获利 |
| A2 | 每条视频至少 **3 个自制画面**（时间轴/图表/标题卡/地图）或真人画面 | "画面是自己组织的"是审核可见的增值 |
| A3 | **真人出现**：开场 15–30 秒或收尾，或关键处画中画；美化自己的脸不需披露 | 最强的真实性与人格信号 |
| A4 | 视频之间**不共用同一模板结构**：至少 3 套开场方式、3 套封面版式轮换 | 反"模板化" |
| A5 | 简介列出**来源**（书/论文/档案链接）与素材署名 | 教育类内容的可信度与 EEAT |
| A6 | 合成内容按规则**披露**：YouTube 仅对"看似真实的合成人物/事件"勾选；国内平台一律声明"含 AI 生成内容"（2025-09-01 法规） | 不披露才是风险；披露本身不影响获利 |
| A7 | 敏感题材（暴力、灾难死亡、政治）用中性叙述，不展示血腥画面，标题不猎奇 | 广告友好度（黄标） |

## B. 结构与节奏

| # | 规则 | 页面检查 |
|---|---|---|
| B1 | **钩子 ≤ 30 秒**（英文 ≤ 75 词 / 中文 ≤ 120 字），含反差、问题或具体数字之一 | 第 1 步：首段字数与是否含数字/问号 |
| B2 | 前 30 秒**不放片头/logo 动画**；片头 ≤ 7 秒且放在钩子之后 | 第 4 步：`auto_title_cards` 不作用于首段 |
| B3 | 一段 = 一个意思，**2–4 句、20–45 秒**；超过 60 秒的段拆开 | 第 1 步：段预计时长 |
| B4 | **画面每 8–12 秒变化一次**：45 秒的段至少 3 个片段或一个视频片段 | 第 3 步：单图长段黄标 |
| B5 | 每 3–5 段一个**章节名**（YouTube 章节 + 标题卡），章节名 ≤ 6 词 | 第 1 步 |
| B6 | 时长：历史/科普长视频 **12–25 分钟**最稳（完播 vs. 广告位）；Shorts 另做 | 第 1 步总预计时长 |
| B7 | 结尾 20 秒：一句总结 + 下集预告，**不要**"点赞订阅"长篇 | 第 1 步末段 |
| B8 | 语速：英文 **150–170 词/分**，中文 **220–260 字/分**；停顿 0.4–0.8 秒 | 第 2 步：按时长/字数算 |

## C. 标题 / 封面 / 简介

| # | 规则 | 页面检查 |
|---|---|---|
| C1 | 标题 **≤ 60 字符**（移动端截断），含数字或具体名词，避免 clickbait 词 | 第 5 步 |
| C2 | 标题公式（轮换）：`The X That Y` / `Why X Happened` / `X Explained in N Minutes` / `How X Changed Y` / 中文：`X 为什么会 Y` / `一次 X，改变了 Y` | 第 5 步给候选 |
| C3 | 封面大字 **≤ 4 词 / ≤ 6 字**，与标题**不重复**（互补），高对比、主体占 1/3、人脸或强符号 | 第 1 步 `thumbnail_text` |
| C4 | 简介前 2 行含核心关键词（搜索展示区），后接章节、来源、署名 | 第 5 步自动组装 |
| C5 | 标签 5–12 个，含 2 个宽词 + 3 个长尾 | 第 5 步 |

## D. 音频与画质

| # | 规则 |
|---|---|
| D1 | 旁白响度 **-16 LUFS**（已默认），BGM 比旁白低 18–22 dB 并在说话时压低（已默认） |
| D2 | 声音固定一个，整个频道一致；真人声或克隆自己的声优先 |
| D3 | 1080p30 起步，静帧用 2× 超采样 + 运镜缓动（已默认）；竖图用模糊填充不裁切（已默认） |
| D4 | 字幕：上传 .srt 字幕轨而不是烧录（利于 SEO 与多语言）；烧录时用底框样式 |

## E. 系列化与频率

| # | 规则 |
|---|---|
| E1 | 以**系列**为单位选题（"X 的十次转折"），封面/标题风格一致，互相引流 |
| E2 | 频率：每周 1–2 条，稳定 > 数量；前 30 条不评估收入，只看 CTR（>4%）与平均观看时长（>40%） |
| E3 | 每 10 条复盘一次：CTR 最高/最低 3 条的封面标题差异；留存曲线最大跌点对应的段 |
