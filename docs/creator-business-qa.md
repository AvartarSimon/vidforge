## Q1：这个想法现实吗？未来趋势和更前沿的方向

**结论**

- ❌ "用 vidforge 批量生产无人出镜的 TTS + 图库解说视频 → 靠平台广告分成赚钱"：2026 年这条路基本已关闭，不建议。
- ✅ "vidforge 当杠杆 + 你本人的真实身份 / 经历 / 专业"：可行，但它是慢变量（12–24 个月见钱），**不能指望它缓解房贷**。
- 三个更前沿的方向：**造铲子（B2B）**、**build-in-public 工程师**、**"AI 时代 40 岁华人工程师在澳洲"的真实叙事**。

**关键依据**

1. 平台政策已明确针对批量 AI 内容：
   - YouTube 2025-07-15 起 YPP "inauthentic content"（原 repetitive content）政策，点名 mass-produced、AI 配音 + 图库 的频道，拒绝或撤销获利。⚠️
   - 中国《人工智能生成合成内容标识办法》2025-09-01 施行；抖音 / 头条要求 AI 内容显式标识并对低质 AI 内容限流，头条 2025 年多轮清理。⚠️
2. 广告分成本身很薄：中文 YouTube RPM 约 US$1–3 / 千次播放（澳洲 / 北美华人受众约 US$3–8）；英文商业 / 科技 / 理财类 US$10–30。抖音广告分成可忽略，钱在星图商单和带货；头条图文按万次阅读只有几元到几十元人民币。⚠️
3. 海外身份限制：抖音 / 头条的创作者收益、星图、带货要中国大陆实名（身份证 + 大陆手机号 + 大陆银行卡）。没有这些 → 只能"发"不能"赚"。
4. **小红书比抖音 + 头条更适合你**（⚠️ 此结论在 [Q7](#q7) 有细化：小红书 2026 主推 2 分钟以上中长视频，不是只能发图文；但它是"分发渠道"而非主阵地）：海外华人生活 / 移民 / 澳洲房产 / 理财是小红书强类目；蒲公英平台 1000 粉即可接商单；广告主（移民中介、房贷 broker、留学、会计）付费意愿明确。⚠️
5. 红海是"泛内容"（历史解说、科普、鸡汤），不红的是交叉点：**墨尔本 × 华人 × 软件工程师 × 40 岁有房贷 × 会用 AI 写代码**。这个交叉点的内容 AI 做不出来，因为需要亲身经历。

**趋势预测（2–3 年）**

- 生成式视频（Veo / Sora / 可灵 / 即梦）把"画面"成本推向零 → 画面不再稀缺，稀缺的是 **信任、第一手信息、人格、分发**。
- 纯"信息搬运 + 配音"的解说内容会被 AI 搜索（Gemini / ChatGPT / 豆包）直接吃掉流量——用户问 AI 就够了，不看你 8 分钟视频。
- 平台持续标记并降权 AI 生成内容，同时奖励真人出镜和真实生活记录。
- 创作者收入结构：广告 → 品牌合作 → 自有产品 / 服务 / 社群。头部以外，广告只是零花钱。
- 三个前沿方向：
  - **a. 造铲子**：vidforge 本身就是产品，卖给"需要视频但没时间做"的人（华人地产经纪、中介、课程作者、小企业）。B2B 收入比 B2C 广告费确定得多。
  - **b. Build-in-public 工程师**：记录"我用 Claude Code 造了 X"，面向开发者。RPM 高、开发者工具赞助多，且给职业和产品导流。
  - **c. 真实叙事**：职场 + 房贷 + AI 焦虑 + 副业，中文，YouTube + 小红书。最有共鸣，广告主最明确。

## Q2：具体方向、方案、90 天执行清单

**原则**：一个主平台、一个人设、一种格式、90 天、每周固定产出。不要同时开 YouTube + 抖音 + 头条；先做主平台，再用 vidforge 的 i18n / 切片做分发。

### 方案 A（首推）：中文 YouTube + 小红书 —「墨尔本码农 Simon」

- 人设：在澳多年、40 岁、有房贷、软件工程师，用 AI 和数据的思维拆解澳洲生活里的钱和事。
- 三个内容支柱（每周 1 条 8–12 分钟长视频 + 2–3 条短视频 / 小红书图文）：
  1. **钱**：房贷 offset / refinance 实测、澳洲税务、super、澳洲 vs 国内生活成本——用自己的数据做图表（vidforge 的 Remotion BarChart 正好用上）。
  2. **职场**：澳洲 IT 怎么不被裁、40 岁转 AI、面试 / 简历、contractor vs permanent。
  3. **AI 实用**：用 Claude / ChatGPT 解决澳洲生活具体问题（写 lease 邮件、看合同、报税），演示型。
- 出镜：至少 **声音是你自己**（不用 TTS），最好露脸或半露脸（屏幕录制 + 小窗）。这是和 AI 内容拉开差距的最低成本动作。
- 变现阶梯：
  - 0–1k 粉：无收入，攒作品；
  - 1k–10k：小红书蒲公英接单（AUD 200–800 / 条）、YouTube 开 YPP（1000 订阅 + 4000 小时公开观看，或 90 天 1000 万 Shorts 播放）⚠️；
  - 10k+：房贷 broker / 移民中介 / 会计软广（AUD 1–3k / 条）、affiliate（券商、保险比价）、付费咨询 / 小课。

### 方案 B：英文 build-in-public（可与 A 并行做短内容，但不要两条长视频线）

- "40-year-old engineer in Melbourne building X with Claude Code"，每周 1 条 10–15 分钟。
- 受众：开发者、indie hacker。变现：RPM US$8–20、开发者工具赞助、产品本身。
- 前提：英语口语能撑住讲解（不需要完美，需要清楚）。

### 方案 C：造铲子 / 本地内容服务（最可能 6 个月内见钱）

- 墨尔本华人地产经纪、房贷 broker、留学中介、餐馆需要小红书 / 抖音 / YouTube 内容但没时间做。
- 套餐："每月 8 条短视频 + 4 条图文"，AUD 800–2000 / 月 / 客户；3 个客户 = 每月 AUD 3–5k。
- 不需要粉丝，需要 5 个案例 + 一页介绍；方案 A 频道就是作品集。

### 90 天执行清单

| 时间 | 做什么 | 看什么数 |
|---|---|---|
| 第 1–2 周 | 定人设与 3 支柱；写 20 个选题；做频道视觉（品牌包）；录 3 条存货 | — |
| 第 3–12 周 | 每周 1 长 + 3 短，雷打不动 | CTR > 4%；前 30 秒留存 > 60%；平均观看时长。低于线改开头，不改选题 |
| 第 12 周 | 复盘：没有一条破 5k 播放 → 问题在选题 / 开头，不在画质；换支柱不换人设 | — |

- 预算 < AUD 500：麦克风 ~150、补光 ~60、Pexels 免费、ElevenLabs 可选。
- 时间：每周 6–8 小时，周末一次批量（脚本 → 录音 → vidforge 出片 → 上传）。

### 不要做的

- 不做历史 / 科普解说（红海 + AI 淹没 + RPM 低）。
- 不用 TTS 配音发抖音 / 头条（限流 + 标识义务）。
- 不买粉、不买赞。
- 90 天内不看收入。

## Q3：房贷焦虑下，低成本、高概率的副业（墨尔本）

**结论**：内容创作是所有副业里"中位数收入"最低的一个（多数人 12 个月后月收入 < AUD 100），它的价值是"期权"不是现金流。房贷压力要靠高概率的事解决。按 **概率 × 收益 ÷ 投入** 排序：

### 1. 主业收入本身是最大杠杆（概率最高）

- 最能消除"怕被裁"的不是不动，而是**手里有 offer**。每半年低强度面试 2–3 家，不一定换，但你会知道市场价和自己的位置。
- 墨尔本 senior / lead 软件工程师约 AUD 150–200k+；AI / LLM 集成经验目前是溢价项——你正在用 Claude Code 做 pipeline、LLM 集成，可直接写进简历。⚠️
- Fair Work / NES：被裁有法定遣散费（按工龄，最多 16 周）+ notice + 年假折现，不是一无所有。算出自己的数，焦虑会具体化。⚠️
- 检查 super 里默认的 income protection 保险覆盖多少。

### 2. 技术接活 / 本地 AI 自动化服务（概率高，直接用现有技能）

- 墨尔本华人小企业（会计所、中介、诊所、餐饮）需要"把重复工作自动化"——你现在的 Claude Code 技能正好。按项目 AUD 2–8k，或按小时 AUD 100–150。
- 渠道：华人商会 / 微信群 / LinkedIn，先做 2 个便宜案例。也可 Upwork / Toptal。
- 注册 ABN（免费，sole trader）；收入报 ATO；设备 / 软件 / 家庭办公室可抵扣。

### 3. 房子本身（概率最高、几乎零技能）

- **出租一个房间**：墨尔本 AUD 250–350 / 周 ≈ 每年 AUD 13–18k。注意出租部分按比例影响主居所 CGT 豁免，租金要报税，但通常仍划算。⚠️
- **offset / refinance**：找 broker 免费评估（broker 从银行拿佣金）。利率差 0.5% 在 AUD 700k 贷款上 = 每年 AUD 3.5k。
- 短租（Airbnb）旺季收益更高但更累，且维州 2025 年起对短租征 7.5% levy。⚠️

### 4. 做小产品（中等概率，长期复利）

- vidforge 打磨成给中文创作者 / 小企业的桌面工具或托管服务（月费 AUD 20–50）。
- 把 solar 分析做成面向澳洲家庭的"太阳能 / 电价分析"小工具（澳洲家庭屋顶光伏渗透率 > 30%，刚需类目）。
- 与方案 B 的内容互相导流。

### 5. 内容创作（低概率、高上限、长周期）

- 见 Q1 / Q2。定位为"给 2 和 4 做展示窗口"，不是主要收入来源——心态上就不会焦虑。

### 关于焦虑本身

- 把"怕"变成数字：应急金几个月？遣散费多少？房贷断供线在哪？多数人算完发现有 6–12 个月缓冲，焦虑就从"模糊的恐惧"变成"可排期的项目"。
- 40 岁 + 没现金积蓄在澳洲不是绝境：super 在强制攒、房贷还的本金也是积蓄、澳洲软件行业需求仍在。
- 副业只选一个主线，不并行三个；每周 6–10 小时是你最稀缺的资源。

### 推荐组合

- **本月**：出租房间 / refinance 评估 + 更新简历投 2 家 + 注册 ABN。
- **3 个月**：接 1–2 个本地自动化 / 视频小单（方案 C），用 vidforge 做作品集。
- **同时**：方案 A 频道每周 1 条，坚持 6 个月再评估。

<a id="q4"></a>
## Q4：用微软 TTS + 画中画真人，能过 YouTube 的 inauthentic content 审核吗？

**结论**

- 这不是"检测 TTS"的问题，**不需要"避开"**。YouTube 官方政策原文明确：AI 工具（脚本、配音、背景、缩略图）是允许的生产辅助；被拒的是"mass-produced、generic、repetitive、template-based"的频道。审核是**整个频道**层面的人工 + 自动评估（看主题、播放最多的视频、元数据）。
- 判定标准一句话："每条视频的实质内容是否明显不同、是否有你自己的观点 / 研究 / 编辑决定"。TTS 配音 + 图库 + **原创研究 / 明确观点** = 可获利；TTS + 图库 + 通用模板脚本 = 不可获利，不管画面多精美。
- 画中画真人是**正解之一**，不是"绕过"：它是最直接的"人做了创作决定"的证据。但更便宜、更有效的人类投入是 **你自己的声音**（每条 20–30 分钟录音）。观众留存和信任对"真声 vs TTS"很敏感，这比露脸重要。
- AI 披露：单纯 TTS 旁白**不需要**勾选"altered or synthetic content"；只有克隆真人声音、或生成"看起来像真实事件 / 人物"的画面才需要。披露本身不影响获利。

**建议的组合（省时间又合规）**

1. 脚本：LLM 起草 → 你改成自己的观点（这是关键的"人类输入"，30 分钟）。
2. 配音：YouTube 长视频用自己的声音；小红书 / 短视频切片可用 TTS。
3. 画面：Remotion 数据图表（你自己的数据 = 原创） + Pexels B-roll + 屏幕录制 + 每条 1–2 段自拍画中画（手机拍，30 秒）。
4. 频道结构：固定片头片尾没问题，但**每条的核心内容必须不同**；不要做"同一模板换个主题"的系列。

**依据**：[YouTube 官方 YPP 政策页](https://support.google.com/youtube/answer/1311392)；[ytgrowth 对 2026 规则的整理](https://ytgrowth.io/blog/youtube-ai-policy)；[faceless.my 对 inauthentic content 的解读](https://faceless.my/youtube/youtube-inauthentic-content-policy-faceless-ai-2026/)；[AI 披露规则整理](https://influencermarketinghub.com/ai-disclosure-rules/)；[YouTube 官方博客：披露合成内容](https://blog.youtube/news-and-events/disclosing-ai-generated-content/)。

<a id="q5"></a>
## Q5：抖音 / 头条怎么"避开"AI 检查？美化后上镜可以吗？

**结论**

- **不要试图避开，主动打标**。2025-09-01 起《人工智能生成合成内容标识办法》施行，抖音有两套机制：创作者自主打"AI 生成"标 + 平台自动检测（隐式元数据 + 模型识别），未标识会被打"疑似使用 AI 生成技术"并**限流 / 处罚**；2026 年 5 月抖音又加强了。**打了标的 AI 内容并不会被限流**——限流的是"低质、重复、未标识"。
- "有大量 AI 视频"是对的，但你看到的多数是：① 已打标、② 靠量堆的账号，单账号收入很低、③ 大量正在被清理。这不是可以模仿的样本。
- 美化后上镜完全可以（美颜滤镜属于常规处理，不需要 AI 标识）；用自己的脸做数字人也可以，但要打标，且**数字人在金融、医疗、教育、保健类目受限**（直播场景明确禁止无人直播）——你的"钱 / 理财"内容要注意。
- 真正的硬约束还是 [Q1](#q1) 第 3 条：抖音 / 头条的创作收益、星图、带货要大陆实名 + 大陆银行卡。**先确认这一条**，否则国内平台只能当分发，不能当收入。

**依据**：[司法部：AI 生成内容强制打标](http://legalinfo.moj.gov.cn/zhfxfzzx/fzzxyw/202509/t20250904_524600.html)；[新华网：多平台出台细则](http://www.news.cn/tech/20250909/fb164c6d092146aa8e13ddc283fe416a/c.html)；[抖音新规实操指南](https://www.sohu.com/a/1020985783_122725103)；[抖音 / 小红书 AIGC 标识 9 问](https://www.byerisk.com/blog/aigc-content-labeling-2026-9-faq)；[数字人直播合规手册](https://www.byerisk.com/blog/ai-digital-human-livestream-2026-compliance-guide)。

<a id="q6"></a>
## Q6：vidforge 这个名字什么意思？

- **vid** = video；**forge** = 锻造炉 / 铁匠铺，引申为"把原料锻造成成品的工坊"。合起来 = "视频锻造厂 / 视频流水线"，对应项目定位"script-to-video assembly line"。
- 这是开发者圈常见的命名套路：SourceForge、Minecraft Forge、ImageForge、Forge（Laravel 的部署工具）……"forge" 暗示"工具 / 生产"而非"创意 / 消费"。
- 纯粹是工程命名，没有营销考量。将来如果做成面向创作者的产品，可以另起中文品牌名，代码仓库名不用改。

## Q7：小红书 vs 长视频；海外华人博主到底谁在涨粉（调查结果）

**先说调查的边界（诚实版）**：小红书站内榜单要登录 App，第三方榜单（新红 / 千瓜 / 灰豚）是付费的，我通过网页搜索**拿不到"澳洲 / 美国 / 加拿大小红书博主粉丝排名"这种表**。下面是：公开可查的行业数据 + 搜索到的具体账号 + 我训练数据里有把握的案例。名字没把握的一律不写。你自己 30 分钟能做的补充调查在末尾。

### 7.1 关于"小红书只能发图片"——这个前提已经过时

- 小红书 2026 年官方重点是 **2 分钟以上中长视频**，完播 30 秒即可进更大流量池。
- 卡思数据拆 2024 年涨粉 TOP500：**纯图文博主 0 个上榜**；视频的关注转化率是图文的 5 倍（1.64% vs 0.34%）。
- 所以你的"长视频"计划和小红书不冲突：YouTube 发 10 分钟原片，小红书发 2–4 分钟精剪版（vidforge 的多段选取 / 复用功能正好干这个）。

### 7.2 关于"粉丝多的都是中外情侣 + 颜值 + 有钱"——你看到的是"生活 vlog"赛道，不是你要进的赛道

- 你描述的那类账号属于**娱乐 / 向往型内容**（剧情、搞笑、颜值、生活方式），它确实是小红书涨粉最快的赛道（剧情 / 搞笑占 TOP500 的 19.6%）。这个赛道的关注理由是"好看 / 有趣 / 羡慕"，你不具备，**也不需要**去竞争。
- 另一个赛道是**实用 / 信息型**：关注理由是"对我有用"。这个赛道的头部案例几乎都长相普通甚至不露脸：
  - **半佛仙人**（B 站 / 公众号，全网千万粉）：从不露脸，画面全是表情包 + 图片，靠自己的声音和犀利观点讲财经 / 商业 / 反诈。这是"图片 + 旁白"能做到的天花板，证明格式不是问题，**观点和信息密度才是**。
  - **小 Lin 说**（前摩根大通，YouTube 百万级）：普通形象、白板 + 图表讲宏观经济，靠专业。
  - 澳洲本地搜到的中文 YouTube 频道（东哥澳洲移民生活频道 / 澳洲香港人 / 土澳 TV / AMEC 澳洲留学网路电台 / 澳洲 Alison 老师）：**全部是中介或从业者做的"服务型频道"**——移民顾问、地产、贷款——内容是他们的获客漏斗，广告费不是目的。这印证了两件事：① 澳洲华人频道天花板不高（几万订阅），② 但**这个圈子的钱在服务和商单，而不是播放量**。
- 小红书涨粉研究的另一条结论：2023 年起趋势是"从精致到细分"——在具体场景下给实用建议的博主，比泛泛而谈的更容易涨粉；2022 年月均涨粉 30 万，2023 年降到 10–20 万，即**涨粉整体变难，细分才有机会**。

### 7.3 关于"澳洲华人太少、想移民的人少了"

- 澳洲华人不少：2021 年人口普查约 139 万华裔、55 万中国出生，墨尔本约 30 万华裔（⚠️ 2026 普查数据出来后更新）。这是一个小但**高客单价**的受众：房贷 broker、会计、保险、移民中介愿意为一个本地精准客户付几百到几千澳元。
- 中文长视频在 YouTube 的受众不是只有澳洲：大陆（翻墙）、台湾、马来西亚、北美华人都看。"澳洲人视角讲钱 / 职场 / AI"对他们同样有异域感和信息差。
- 移民咨询不是你的赛道，不用做。你的赛道是**"已经在澳的普通华人家庭怎么过得更好"**：房贷、电费（你正好有太阳能数据）、super、税、裁员应对、AI 工具。这些是刚需、常搜、且几乎没有工程师视角的人在做。

### 7.4 给你的具体、可执行的结论

1. **人设不靠脸，靠"工程师 + 数据 + 观点"**：每条视频至少有一个你自己算出来的数字 / 图表（房贷 offset 省多少、太阳能一年回本几年、裁员遣散费怎么算），这是 AI 内容农场做不出来、也是审核眼里最"原创"的东西。
2. **格式：半佛式**——自己的声音 + 图表 / 图片 / 表情包 / 屏幕录制，露不露脸随意。vidforge 已有的 Remotion BarChart / Timeline 就是为这个准备的。
3. **平台：YouTube 长视频为主，小红书 2–4 分钟精剪版分发**；抖音 / 头条在实名收款问题解决前只做分发或干脆不做。
4. **选题来源不是灵感，是搜索词**：小红书搜"墨尔本 房贷"、"澳洲 super"、"澳洲 裁员"，按"最多点赞"排序，看前 20 条谁在做、缺什么角度；YouTube 同理。这半小时的功课比我给你任何名单都有用。

**你自己 30 分钟能做的补充调查**：① 小红书 App 搜"墨尔本"/"悉尼"，筛"视频"、排序"最多点赞"，记录前 30 条的账号类型；② [playboard.co](https://playboard.co/en/search?q=%E7%A7%BB%E6%B0%91%E6%BE%B3%E6%B4%B2) 搜"澳洲"看中文频道订阅数；③ 新红数据 / 千瓜有免费版可以看单个账号粉丝画像。

## Q8：注册 ABN 的目的是什么？

**结论**：ABN 是"以生意身份收钱"的前提，不是为了 YouTube 广告费。**没有客户之前不用注册**；有第一个付费客户时再注册，免费、15 分钟、[abr.gov.au](https://abr.gov.au) 在线办。

**它具体解决什么**

1. **开发票**：澳洲企业付款给你时要 ABN；发票上没有 ABN，对方按规定要**预扣 47%**（no-ABN withholding）。品牌软广、本地服务费都是这条。
2. **GST**：年营业额超 AUD 75k 必须注册 GST（在 ABN 之下）；没到不用。
3. **抵扣**：ATO 区分"hobby"和"business"，有 ABN + 有规律的经营是"business"的证据，设备 / 软件 / 家庭办公室按比例抵扣才站得住。
4. **平台要求**：部分本地品牌、MCN、平台（例如给澳洲商家做内容服务）合同要求 ABN。

**不需要 ABN 的收入**：YouTube AdSense（打到个人账户，年底作为个人收入申报即可）；小红书蒲公英商单（走中国身份 / 银行，与 ABN 无关——海外博主常见做法是通过 MCN 或国内亲属账户收款 ⚠️）。

**风险 / 副作用**：ABN 本身零成本，但注册后要在年度税表里多报一节 business schedule；用 sole trader 就够，不要一上来开公司（Pty Ltd 每年 ASIC 费 + 会计费约 AUD 1–2k）。

## Q9：接单做 AI 自动化，别人为什么找我？值得吗？

**结论**：你的质疑是对的——**如果目标是"不忙且赚钱"，服务型接单不适合你**。它是时间换钱，边际不会变好。只有满足下面三条之一才做：

1. **有效时薪 ≥ 主业时薪 × 1.5**（墨尔本 senior 工程师折算约 AUD 80–100/h，所以接单要 ≥ AUD 120–150/h 或固定价折算后达到）；
2. **交付物可复用**（做完第一家，第二家 80% 一样，逐渐变成产品）；
3. **它是内容 / 作品集素材**（一单换一条视频 + 一个案例）。

三条都不满足的单，拒绝。

**"AI 让非码农也能做软件，为什么找我？"——诚实的回答**

- 简单的（一个网页、一个自动回复）：确实不需要你，客户自己用 AI 做，或找 Upwork 上 AUD 20/h 的人。**别碰。**
- 复杂的（连 ERP / 会计系统 / 银行数据、多人用、要长期跑）：客户找的不是"会写代码"，是**"出了问题有人负责、下个月还在"**——这是 AI 和一次性外包都给不了的。大公司不接 AUD 5k 以下的单，本地小公司缺的是"懂中文、懂他们行业、能到现场"的人。这个缝隙存在，但它是"忙"的生意。
- 所以真正的可选项只有一种：**产品化的小服务**——固定范围、固定价格、可批量（例如"给华人地产经纪做每月 8 条房源视频"、"给会计所做 ATO 邮件自动分类"），做到第 3 家就把它变成工具。这和 vidforge 的方向重合，也和 [Q3](#q3) 的第 4 项（小产品）是同一条路。

**和你的时间预算对照**：每周 6–10 小时只够做一件事。排序建议：房间出租 / refinance（一次性动作）> 主业保底（面试）> 一条内容线（长期期权）> 接单（除非满足上面三条之一）。

<a id="q10"></a>
## Q10：做 FND（功能性神经障碍）账号——五个顾虑的逐条分析

**总结论**：这是整个对话里**第一个你有别人复制不了的优势的方向**：家属的第一手经历 + 中文 + 工程师读论文的能力 + 身在有 Alfred / Austin 专科门诊的墨尔本。受众小、钱少、慢，但"内容太多、卷不过颜值"的问题在这里不存在——中文互联网上目前**没有一个 FND 患者 / 家属视频账号**。前提有两条：① 定位必须是"**家属笔记 + 翻译权威资源**"，不是"科普"；② **你爱人的同意和主导权**——她是内容的主体，不是素材。

### 调查到的事实

- 患病率：80–144 / 10 万（系统综述），比多发性硬化常见；澳洲 AIHW 估计 2.15 万人（作者认为低估），年住院 6,100 次，四分之三是女性。澳洲专科服务"稀缺"、"需求持续超过容量"、诊断延误和碎片化照护普遍，患者普遍经历"否认、不信、被打发"。墨尔本有 Alfred 功能性癫痫门诊（2019，全澳首个公立）、Austin 功能性神经科门诊（2013）和住院服务（2023）。
- 中文内容现状：网页能搜到的只有澎湃 / 知乎一篇长文、家医大一篇、台湾李医师 2026 年的卫教系列、仁济医院 JNNR 的"FND 联盟"专栏。**没有找到任何中文患者 / 家属视频账号。**按患病率外推，中文世界潜在患者百万级（⚠️ 外推估计），家属 ×3。
- 英文 YouTube 现状（2026 年 Frontiers 研究，最热 50 条）：协会 30%、健康资讯频道 24%、医院 20%、**患者只占 10%、医生 6%**；整体质量"中等"，互动量与准确性无关；作者呼吁更多有证据、以患者为中心的内容。健康资讯频道的互动最高。
- 平台规则：
  - 抖音：**非认证账号不能发医疗类内容**（认证门槛三甲主治以上）；2025-08 四部门通知"严禁无资质账号生产发布专业医疗科普内容"，但"分享传播真实健康经历"允许，须标注信息来源。→ 国内平台只能做"家属经历"，不能叫"科普"。
  - YouTube：医疗虚假信息政策针对"与 WHO / 当地卫生部门相悖的预防 / 治疗 / 否认"类内容；FND 不在特定名单里，但不能宣称疗法、不能反对主流治疗。YouTube Health 的"权威来源"标签只给持牌专业人士，你拿不到，但正常获利不受影响。英文健康类 RPM 约 US$8–15，中文更低。
- 治疗事实（纠正"没有药可治"）：没有特效药是对的，但 FND 被认为是**可治疗、可改善**的：专科物理治疗、CBT、患者教育是主流路径。证据是混合的——Physio4FMD（Lancet Neurology 2024，英国 11 家医院 RCT）12 个月的主要指标（SF-36 身体功能）没有显著优于常规治疗，但心理健康等次要指标改善；Monash 2025 年的线上协作治疗项目让功能性发作在数周内几乎减半。这种"证据到底怎么说"的翻译，正是家属账号最有价值的内容。

### 顾虑 1：向苦命人赚钱不道德

- 前提要修正：观众看 YouTube 广告不花钱；平台广告是"零成本给观众"的收入，患者社区普遍接受。不能接受的是：**向患者卖"疗法 / 保健品 / 课程"**，以及没披露的软广。
- 患者社区的通行伦理：① 不向患者卖任何声称有疗效的东西；② 支持是自愿的（会员 / Patreon / 爱发电），并明确"付不起的人内容一样全部免费"；③ 商单只接自己在用、且披露的东西（辅具、远程物理治疗平台、NDIS 服务商）。
- 更重要的：**钱不该来自患者，应来自机构**——见"变现"。

### 顾虑 2：不是医生，怕误导

- 解决办法是定位，不是知识量："**我不解释疾病，我翻译权威来源 + 记录我们的经历**"。硬规则：
  1. 每一条医学陈述都指向来源：neurosymptoms.org（Jon Stone 教授）、FND Hope、FND Australia、仁济 FND 联盟、Mayo Clinic 中文页；
  2. 永远不建议改变治疗、不评价具体医生、不推荐药物 / 补剂；
  3. 固定免责声明 + "请与你的神经科医生讨论"；
  4. 找专业人士做嘉宾：墨尔本会中文的神经科医生 / 物理治疗师 / OT，或 FND Australia Support Services 的同行支持者——这是独一无二的内容，也是最好的"纠错机制"；
  5. 请 FND Australia Support Services 或 FND Hope 审阅关键视频脚本（他们有健康专业人员培训项目，通常欢迎多语言材料）。
- 工程师视角是天然优势：FND 的标准解释就是"硬件没坏，是软件出了问题"——一个软件工程师讲这个比喻，比任何人都可信、都生动。

### 顾虑 3：受众太小

- 小，但**零竞争 + 搜索意图极强 + 极高粘性**：每一个搜中文 "FND / 功能性神经障碍 / 功能性癫痫 / 心因性发作" 的人都会落到你这里。现实预期：2 年 5k–30k 订阅，但每条视频的观看时长和评论密度会远高于泛内容。
- 受众不只患者：家属、被贴"癔症 / 转换障碍 / 躯体化"标签而不知道 FND 的人、中国的神经科 / 康复科 / 精神科医生和学生（仁济有 FND 联盟说明临床界有兴趣）、台湾（2026 年有卫教系列，YouTube 使用率高）。

### 顾虑 4：内容会枯竭

- 不会，只要按结构做。选题池（随手列 60+）：
  - 病：各亚型（功能性发作、运动 / 无力 / 震颤 / 步态、感觉、认知、PPPD 头晕、伴随的疼痛 / 疲劳 / 焦虑）；诊断（阳性体征、为什么 MRI 正常、误诊史）；治疗路径（专科物理治疗、CBT、OT、言语治疗、住院项目）；研究进展（每季度读 2 篇论文翻译成人话）。
  - 澳洲系统：急诊怎么应对、GP → 神经科 → 等待名单、Medicare / 私保 / NDIS / Centrelink / 工作权利 / 请假、Alfred / Austin 门诊怎么进。
  - 家属：照护者倦怠、夫妻关系、怎么跟国内父母解释、孩子、工作与照护的平衡、发作时的应对（拍手机教程）。
  - 互动：评论区问答、患者 / 家属连线、医生访谈、中澳（台）差异。
- 节奏：这个赛道每月 2 条就够，比每周 1 条泛内容更可持续。

### 顾虑 5：怎么变现

按"来自患者 → 来自机构"排序：

| 层 | 来源 | 现实预期 |
|---|---|---|
| 0 | YouTube 广告 | 中文健康类 RPM 低，1 万订阅约 AUD 50–200 / 月 |
| 1 | 自愿支持（会员 / Patreon / 爱发电），明确"付不起一样免费" | 几十到几百 / 月 |
| 2 | **机构付费**：给医院 / 诊所 / FND 组织 / NDIS 服务商制作中文患者教育视频（正是 vidforge 干的事）；维州多元文化健康、CALD 健康素养类资助；资源本地化（中文版 neurosymptoms.org / FND Hope 材料）；华人社区讲座 | 一个合同 AUD 2–10k；年 1–2 个 |
| 3 | 产品：双语症状 / 发作日记 App（你能写）、双语 FND 家属手册（低价 + 免费版） | 长期，小额 |
| 4 | 间接：证明你能做"AI + 医疗内容本地化"，给 [Q9](#q9) 的产品化服务背书 | 最值钱但最慢 |

第 1 年基本为零；第 2 年几百 / 月 + 可能 1 个机构合同。**它解决不了房贷**，但它是唯一你不会因为"卷不过别人"而放弃的方向——坚持 6 个月的概率比其他方案高得多。

### 平台与格式

- 主：YouTube（全球华语，含台湾、北美、澳洲）；B 站（大陆长视频 + 知识区）；小红书（患者社区活跃，"真实经历"允许，打好来源标）；微信公众号 / 知乎（文字版，覆盖大陆搜索）。**抖音 / 头条不做**（医疗类非认证不能发，"家属 vlog"能发但没有价值）。
- 格式：你的声音 + Remotion 示意图（"硬件 / 软件"比喻、治疗路径流程图、等待时间时间线）+ 屏幕演示（怎么读 neurosymptoms.org）+ 少量出镜。不需要拍摄她的症状。
- 第一批 5 条：① 我们花了 X 个月才拿到的诊断；② 一个程序员理解"硬件没坏，软件出错"；③ 澳洲 FND 就医路径（GP → 神经科 → Alfred / Austin）；④ neurosymptoms.org 中文导读；⑤ 家属最常做错的 5 件事（引用 FND Hope 的家属指南）。

### 关于她

- 她是否愿意、愿意公开到什么程度（不露脸 / 不提名字 / 只讲家属视角）——先谈这个，再谈频道。
- 建议她共同拥有这个账号（决定权），而不是"你讲她的病"。很多患者说被公开讲述是二次伤害，也有很多人说讲出来是康复的一部分——这只能她决定。

## Q11：FND 账号具体在哪些平台、怎么做视频（出镜 vs vidforge）

**结论**：不是二选一，是**三种视频类型各用各的生产方式**。信任靠人（出镜 / 真声），产量靠流水线（vidforge）。

### 平台（按优先级）

| 优先级 | 平台 | 发什么 | 为什么 |
|---|---|---|---|
| 1 | YouTube | 10–15 分钟原片 + 章节 + 字幕 | 全球华语（台湾、北美、澳洲、大陆翻墙），搜索长尾，广告 / 会员 |
| 2 | B 站 | 同一文件直传 | 大陆长视频主阵地，知识区受众接受"家属讲述 + 引用来源" |
| 3 | 小红书 | 2–4 分钟精剪 + 一篇图文笔记（来源清单） | 患者社群活跃；"真实经历"允许，打好来源标 |
| 4 | 微信公众号 | 视频文字稿 | 大陆患者搜索靠微信 / 百度，视频进不去 |
| 5 | 知乎 | 在已有 FND 问题下答题，链接视频 | 现有中文 FND 内容就在这里，流量精准 |
| ✗ | 抖音 / 头条 | 不做 | 医疗类非认证不能发；"家属 vlog"能发但没价值 |

### 三种视频类型与生产方式

| 类型 | 内容 | 生产方式 | 每条耗时 | 频率 |
|---|---|---|---|---|
| A 经历叙事 | "我们的诊断历程"、"发作那天我做了什么"、"跟国内父母怎么解释" | **你出镜或至少真声**，手机 + 补光 + 领夹麦，谈话式，一镜到底再剪 | ~3 h | 每月 1 |
| B 资源导读 / 研究翻译 | neurosymptoms.org 导读、"Physio4FMD 到底说明了什么"、"澳洲就医路径" | **vidforge 流水线**：你读原文 → LLM 起草 → 你改成自己的话 → 真声录音（TTS 只做样片校节奏）→ 屏幕录制 + Remotion 图表 / 流程图 + 少量 Pexels → 出片 + 字幕 + 章节 | ~5 h | 每月 1 |
| C 访谈 | 会中文的神经科医生 / 物理治疗师 / OT / 同行支持者 | Zoom 录制；vidforge 只做片头片尾 / 字幕 / 章节 | ~3 h + 约人 | 每季度 1 |

依据：Frontiers 2026 对 YouTube 上 FND 内容的分析——"健康资讯型"（讲解类）互动最高，"患者视角"最稀缺（10%）。两者都做，互相导流。

### 这个受众特有的制作规范

- **字幕烧录、语速放慢、少闪烁 / 少快切、不用刺耳音效**——功能性发作、认知和视觉症状患者对这些敏感；这既是可及性，也是和"AI 内容农场"最直观的区别。
- 每条视频固定"来源卡"（Remotion TitleCard 即可）+ 简介里固定免责声明 + 危机资源（Lifeline 13 11 14、Beyond Blue）。
- 评论区置顶规则："这里不提供医疗建议"。
- 不拍她的症状；她决定露不露脸、提不提名字。

## Q13：AI 使用技巧分享值不值得做？AI 创业怎么做？

### 13.1 "AI 技巧 / 免费平台 / 开源平台 / AI 创业案例"类内容

**结论：这是中英文两边都最饱和的赛道，不建议作为主线。**

- 行业判断（澎湃 / 36 氪 2026-05）："AI 博主赛道已从技术红利期进入内容深耕期"。头部是 **秋芝 2046**（全网 245 万，前互联网产品经理，全职测评，B 站 AI 春晚总导演）、**跟李沐学 AI**（113 万，亚马逊首席科学家）、AIGC 创作类（荒蛋记录员 78 万）、虚拟博主。变现四条：品牌广告、卖课（文中原话："借'AI 造富神话'收割知识焦虑"）、自研产品、平台激励——文章**没有给出任何具体收入数字**，本身就说明问题。
- 赢的条件只有两种：**资历**（李沐）或**全职速度**（秋芝）。你两者都不是，而且这类内容是 AI 搜索最先替代的——"哪些免费 AI 平台"问一句 ChatGPT 就有。
- "AI 创业成功案例"更是二手信息，零壁垒。
- 唯一能做的形态：**AI 用在一个具体场景**——"用 Claude Code 给澳洲家庭算电池回本"、"用 AI 翻译医学资料照顾家人"。技巧是副产品，场景是主体。这就是 [Q12](#q12) 第 4 条。

### 13.2 AI 创业怎么做——数据

- 独立开发者产品收入分布（2026）：**54% 收入为 0**（2023 年以来没变）；~25% < $1k MRR；~15% $1–10k；~5% $10–100k；~1% > $100k。前 5% 拿走 70%+ 的收入。
- 什么在赢：**垂直、无聊、具体、痛**（"给会计的 SaaS"、"地产经纪的流程自动化"、"牙科诊所的合规工具"），24 个月时单人 B2B 收入是 B2C 的 4 倍以上。
- 时间：有 AI 工具后到 $5k MRR 约 4–6 个月（此前 12–18 个月）；到 $10k MRR 中位数仍是 12–18 个月。
- Marc Lou：3 年 25 个项目，12 个盈利，1 个大成功，年入 $103 万——**成功率 4%，靠的是量和快速放弃**。
- 一人公司：仅约 20% 稳定盈利，深圳 OPC 圈一年留存不足 10%。"AI 降低了实现门槛，商业能力仍是核心变量"。
- 最常见死法：先建后验证；市场选错（"失败源于选了不商业的市场，不是做得差"）。

### 13.3 给你的创业方案

**原则**：不辞职；不做"给所有人的 AI 工具"；不做给创作者的工具；做一个你**有入口**的垂直市场。

**推荐主线：澳洲家庭电池 / 太阳能决策工具**（[Q12](#q12) 第 2 条）

| 阶段 | 做什么 | 判据 |
|---|---|---|
| 第 1–4 周 验证 | 一页 landing（"上传电费单，3 分钟算出电池回本年限"）；在华人群 / 本地社群找 20 个有光伏的家庭免费算，记录他们真正问的问题；联系 5 家安装商问"合格 lead 你付多少" | ≥ 10 人愿意留邮箱 / 微信；≥ 1 家安装商给出 lead 价格 |
| 第 5–8 周 建 | 用你的 solar 代码 + Claude Code 做最小版：输入电费单 / 用电曲线 → 回本估算 + 报告 PDF；中英双语 | 能给 20 个验证用户出报告 |
| 第 9–12 周 卖 | 免费报告换邮箱；报告末尾"要报价？"→ 安装商 lead；同时发 3 条"用数据算电池"视频（vidforge） | 90 天内第一笔 affiliate / lead 收入，否则砍或转向 |
| 之后 | B2B：给安装商的"客户预评估"白标工具（月费） | 3 家付费安装商 = 可持续 |

- 成本：域名 + 托管 < AUD 30/月；LLM 调用按量。
- 合规：ABN 在第一笔收入时注册；affiliate 必须披露；不承诺节省金额（用"估算"）；不碰电工 / 安装本身。

<a id="q14"></a>
## Q14：美国历史频道——时间线 / 人物线 / 事件线选哪个，怎么差异化

**结论：主线用「事件线（问题驱动）」，人物线做支线系列，时间线做 Shorts 格式，三者共用一套素材。**

先说前提（[Q1](#q1) 已说过，这里不再展开）：历史解说是最拥挤、最容易被 AI 内容淹没的赛道，YouTube 的 inauthentic 政策也最盯它。能做的条件是：**自己的声音 + 一个别人没有的固定角度 + 每条视频有自己画的地图/时间线（Remotion）**。满足这三条，就按下面做。

### 三条线的比较

| | 时间线（逐年） | 人物线 | 事件线（问题驱动） |
|---|---|---|---|
| 已有账号 | 英文有 "History of the USA: Every Year"（地图动画）、TimeGhost 的 WWI/WWII 逐周；**中文没有逐年系列** | 中英文都很多（华盛顿、富兰克林、林肯是热门） | 中文有：小鸣说（独立战争一口气看完）、六度世界（起因/过程/后果）、王局（时政切入）、肥洲纪录片（宪法史）、BBC 中文 |
| 单条能否独立成立 | ❌ 弱年份没内容，观众必须从第一集看 | ✅ | ✅ 每条回答一个问题 |
| 搜索流量 | 低（没人搜"1791 年美国"） | 中 | **高**（"美国为什么能独立""美国宪法为什么这样设计"是常搜问题） |
| 可持续性 | 250 年 = 250 集，前 30 集就会枯竭（1790–1810 年代乏味） | 有限（重要人物约 40–60 个） | 无限（每个事件可拆多个问题） |
| 适合 vidforge | ✅ 地图 + 年份卡片 | ✅ 画像 + Ken Burns | ✅ 档案画 + 地图 + 时间线卡片 |
| 结论 | 做成 **Shorts 系列**（"美国这一年 · 1776"，60 秒） | 做成 **事件线的支线**（讲到制宪会议时出"麦迪逊"一集） | **主线** |

### 事件线的差异化（中文受众）

1. **固定角度：把美国当一个"系统"来讲**——你是工程师，制衡、联邦/州权、选举人团、修正案机制，全是"系统设计"问题：为什么这样设计、设计时想防什么、后来哪里失效。这是现有中文频道没有的角度（他们要么讲故事，要么讲时政）。
2. **"同一年，中国在干什么"**——每条视频固定一个 30 秒环节：1776 年 = 乾隆四十一年，1787 年制宪 = 乾隆修四库全书。中文观众对这种平行对照有天然兴趣，成本几乎为零，且 AI 内容农场不会做。
3. **不碰时政**——不评价当下政党、选举、总统。讲到"对今天的意义"止于制度层面。这既是安全，也是和王局那类频道的区隔。
4. **每条都有自己画的图**：一张地图（Remotion）或一条时间线，让"这是这个频道画的"成为识别度。

### 前 12 条选题（每条 8–12 分钟，一个问题）

1. 英国为什么会丢掉北美——七年战争的账单
2. 波士顿倾茶：一场关于税的争吵怎么变成战争
3. 莱克星顿的第一枪：谁先开的枪，为什么说不清
4. 《常识》：一本小册子怎么把"不满"变成"独立"
5. 独立宣言：杰斐逊删掉了什么
6. 华盛顿为什么能赢——他其实输了大多数战役
7. 法国为什么要帮美国（并把自己帮破产了）
8. 《邦联条例》：美国第一次建国为什么失败
9. 制宪会议：55 个人怎么在四个月里设计一个国家（系统设计视角）
10. 联邦党人文献：麦迪逊怎么说服纽约
11. 权利法案：为什么先有宪法，后有"权利"
12. 华盛顿为什么只干两届——先例比法律更硬

### 人物支线 & Shorts

- 人物支线：主线讲到谁就出谁（麦迪逊、汉密尔顿、富兰克林、亚当斯夫妇），一条 6–8 分钟，复用主线素材。
- Shorts："美国这一年"，逐年 60 秒（地图 + 3 件事 + 中国同年），从 1775 起，每周 2 条，从主线视频里切。

### 把制作变快（对应本次改动）

- **一键配图**已改成立刻搜图下载：故事板马上出缩略图，60 段约 5–7 分钟后台跑；来源选 **Commons**（历史画/地图/老照片，公版），不满意的段再点开换。
