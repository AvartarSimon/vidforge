## 1. 先分清两件不同的事 {#分类}

"做一个独特的声音"其实是两条完全不同的技术路线，免费程度和上手难度都不一样：

- **A. 声音设计（Voice Design）**：不用录任何真人音频，纯靠一段文字描述（"四十岁左右的男声，低沉温暖，纪录片解说感"）合成一个全新的、世界上不存在的声音。不是克隆谁，天然没有肖像/声音授权问题。
- **B. 声音克隆（Voice Cloning）**：录一小段（几秒到几分钟）**你自己**的声音样本，AI 学习你的音色，之后用这个音色念任何文字，听起来像"你在说话"。这个必须录你自己的声音，不能拿别人的声音去克隆（法律和平台条款都不允许）。

vidforge 目前接的是 **A（声音设计）**，两个引擎都已经在第2步"配音"→"✨ 设计品牌声音"里能直接用。下面第2、3节把两条路线的所有免费选项都列出来。

## 3. vidforge 里已经能直接用的两种 {#已接入}

### VoxCPM2（推荐：完全免费、本地、可商用）
- 第2步"配音"页，声音输入框旁边点 **"✨ 设计品牌声音…"**，引擎选 VoxCPM2。
- 首次要自己在实际渲染的机器上装：`pip install voxcpm soundfile`（QUICKSTART.zh.md 里有完整步骤）。
- 纯 CPU 非常慢（实测 13 秒试听要跑 8.5 分钟），建议有独立显卡再用；没有的话优先用 ElevenLabs。
- 生成的声音存在你自己电脑上（`~/.vidforge/voices/voxcpm/`），不联网、不花钱、没有月度额度限制。

### ElevenLabs Voice Design（推荐：免速度快，免费额度够用）
- 同一个弹窗，引擎选 ElevenLabs。
- 需要先去 elevenlabs.io 注册，Profile → API keys 拿一个 key，粘贴到 vidforge 的"系统状态"面板保存（见下方）。
- 免费账号每月约 1 万 credits，够偶尔设计+配一些旁白；大量长视频建议搭配付费档位或者干脆用 VoxCPM2。

## 4. 没接进 vidforge、但免费/开源值得知道的方案 {#其它方案}

这几个是真正的**声音克隆**（用你自己的录音训练），vidforge 目前没有集成，如果你想要"AI 用我自己的声音念稿子"这种效果，可以先在对应工具里单独生成音频，再当成"本地文件"上传到 vidforge 当配音用：

- **Coqui XTTS-v2**（开源，GitHub: coqui-ai/TTS）：只要 6 秒左右你自己的干净录音，就能零样本克隆音色，支持中英等 17 种语言。本地跑，一次装好永久免费，需要有一点 Python/命令行基础。
- **OpenVoice V2**（开源，MyShell.ai）：思路类似 XTTS，额外能单独调语气/语速/情绪，跟音色分开控制。同样本地跑、免费、需要一点技术基础。
- **ElevenLabs Instant Voice Cloning**：网页操作，上传 1-2 分钟你自己的录音，几分钟出一个克隆声音，免费额度内可用，但要克隆效果稳定通常需要付费的 Professional Voice Cloning。

⚠️ 这三个都需要你上传/录制**你自己**的声音样本——不能拿网上任何人（包括公众人物、网红）的录音去克隆，这既违反几乎所有平台的条款，也可能构成侵权。

## 5. 一个不建议做的方向 {#风险提示}

不要用这些技术去克隆某个**具体的、可识别的真人**（哪怕是你朋友、网红、名人）的声音用在你的频道里，即使技术上做得到。这类"声音换脸"内容容易被当成未经本人同意的仿冒/深度伪造，YouTube 等平台对"合成人物内容"有强制披露要求，处理不好会有版权投诉、平台处罚甚至法律风险。vidforge 里"设计品牌声音"这条路（A 类，凭空设计一个不存在的声音）从根上就没有这个问题，这也是为什么 vidforge 目前只接了这一类。

## 6. 做完之后：以后所有文字它都会念吗？{#会不会发声}

**会。** 不管是 VoxCPM2 还是 ElevenLabs，"设计声音"只是**做一次**的动作，做完之后你会得到一个可以反复使用的声音（VoxCPM2 是保存在本地的"名字"，ElevenLabs 是一个 voice_id）。之后在项目里把声音设成这个名字/id，**你给它什么文字，它就念什么文字**，不限于设计时试听的那段样例——整部片子几十段旁白都可以用同一个声音，vidforge 每段落自动调用。

但两者的"能一直用"含义不太一样：

- **VoxCPM2（本地）**：只要这台电脑上还装着 VoxCPM2、`~/.vidforge/voices/voxcpm/` 里的配置文件还在，就能无限次、免费生成任意文字的音频，没有月度用量上限（限制只是你自己电脑的算力和时间）。
- **ElevenLabs（云端）**：声音本身长期保留在你的账号里，但**每次真正生成一段新的旁白音频**都要消耗当月的 credits 额度——免费版每月约 1 万 credits，超了要么等下个月刷新要么升级付费档。也就是说"声音"是免费长期保留的，"用这个声音念多少字"才是真正花配额的地方。

## 6.5 声音存在哪、怎么搬到别的电脑、怎么脱离 vidforge 用 {#搬运}

以 VoxCPM2 里保存的 `Simon1` 为例。

**存在哪**：`~/.vidforge/voices/voxcpm/Simon1.json`（Windows 下是 `C:\Users\<你>\.vidforge\voices\voxcpm\Simon1.json`），内容只有两个字段：

```json
{ "description": "四十岁左右，磁性，有魅力，低沉，温暖，专业，调", "seed": 776455128 }
```

**这就是全部**——没有音频文件，也没有模型权重。声音 = 这段描述 + 这个随机种子 + VoxCPM2 模型。三者相同，出来的声音就相同。`~/.vidforge/voices/voxcpm_<时间戳>_1.wav` 只是当时的试听样本，不是声音本体。

**能念任意文字吗**：能。它是 TTS，给什么文字念什么，不限于设计时那段样例，也不限语言（VoxCPM2 支持 30 种语言 + 9 种中文方言）。唯一的限制是算力：没有独显的机器上约 40 倍实时（十几秒音频要跑几百秒），实际使用需要 NVIDIA 显卡，或 Apple Silicon（未实测）。

**搬到别的电脑**：拷那个一百多字节的 JSON 就够了。新电脑上：

```bash
pip install voxcpm soundfile          # 首次运行会下载约 4.7 GB 模型到 ~/.cache/huggingface
mkdir -p ~/.vidforge/voices/voxcpm && cp Simon1.json ~/.vidforge/voices/voxcpm/
```

**脱离 vidforge 用**（给剪映、Premiere、播客生成 wav）：仓库里的 `tools/say.py` 是一个不依赖 vidforge 的独立脚本。

```bash
python tools/say.py --voice Simon1 --text "今天我们讲一个关于火山的故事。" -o out.wav
python tools/say.py --voice Simon1 --file script.txt --split -o narration/   # 每行一个 wav
python tools/say.py --desc "四十岁左右，磁性，低沉，温暖" --seed 776455128 --text "…" -o out.wav
```

最后一种连 JSON 都不需要——把描述和 seed 记在别处即可。反过来说：**这两个值就是你的声音，记下来比备份任何音频都重要。**

**ElevenLabs 设计的声音**不一样：voice_id 在它的服务器上，换电脑只要同一个账号的 API key 就能用，但用量受账号额度限制；脱离 vidforge 就是直接调它的 API。

## 7. 给普通用户的建议路径 {#建议}

- **只是想要个听起来有辨识度、不是默认 AI 腔的声音，不介意可能不是真人级别自然度** → 用 VoxCPM2，一次装好，之后完全免费，适合长期高频产出。
- **想要更自然、更快出效果，产量不算太大（每月几条视频）** → 用 ElevenLabs Voice Design 免费额度，够用就不用折腾本地环境。
- **真的想要"AI 用我自己的声音念稿"（B 类克隆）** → 先用 Coqui XTTS-v2 或 OpenVoice 在本地单独试录、单独生成，满意了把生成好的音频当"本地文件"上传进 vidforge 对应片段；这条路 vidforge 还没做进 UI 里，需要你在工具外面单独操作一步。
- **不要**为了效果去克隆别人的声音，也不要把 A/B 两类混淆导致误觉得"设计声音"就是"克隆声音"——两者出发点完全不同。
